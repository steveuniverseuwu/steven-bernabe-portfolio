## 📌 Project Overview

This is the personal portfolio website of **Steven Benedict T. Bernabe**, a final-year Bachelor of Science in Information Technology student at **Bukidnon State University**.

The website is engineered from scratch using semantic **HTML5**, modern **CSS3 (Grid & Flexbox)**, and vanilla **JavaScript (ES6+)**. It is fully responsive, highly performant, accessible, and features an interactive theme-switching engine, tabbed modal viewers for QA test deliverables, a functional contact form with client-side validation, and dynamic GitHub API repository integration.

* **Live Deployed URL:** [https://steven-bernabe-portfolio.vercel.app](https://steven-bernabe-portfolio.vercel.app)
* **GitHub Repository:** [https://github.com/steveuniverseuwu/steven-bernabe-portfolio](https://github.com/steveuniverseuwu/steven-bernabe-portfolio)

## 🛠️ Technologies Used

* **Frontend:** Semantic HTML5, CSS3 (Modern Flexbox, CSS Grid, Custom Properties/Variables), Vanilla JavaScript (ES6+).
* **Typography & Icons:** Bricolage Grotesque, IBM Plex Sans, Inline Scalable Vector Graphics (SVG).
* **APIs & Interactivity:** GitHub REST API (`https://api.github.com`), HTML5 Dialog API (`<dialog>`), LocalStorage Web API.
* **Deployment & Hosting:** Vercel (CI/CD integrated with GitHub `main` branch).
* **Version Control:** Git & GitHub.

## 🚀 Key Features & Sections

### 1. Home Section
* Professional introduction, headshot photo, and short bio.
* Dynamic typing animation banner (*"Welcome to my QA portfolio"*).
* Quick call-to-action buttons (View Projects, Get in Touch, Download Resume).
* Highlights Dean's Lister honors, graduation year, and degree credentials.

### 2. Projects & QA Deliverables Section
* **ChainGuard (Capstone Project):** Blockchain-based digital evidence integrity system. Features interactive tabbed modal dialogs displaying real-world QA artifacts (Test Plan, Test Cases, Bug Report DEF-042, and Execution Summary).
* **Interactive Web Developer Portfolio:** Responsive personal website built from scratch with custom theme engines and live GitHub API integration.
* **IT Asset & Helpdesk Tracking Portal (Mock Prototype):** Conceptual system for tracking hardware inventory, repair status, and support ticket triage.
* **Dynamic GitHub Repositories (Bonus):** Asynchronously queries the GitHub REST API (`api.github.com`) to dynamically render active repositories with descriptions, language tags, and star counts.

### 3. Contact Section & Interactive Form
* Fully functional client-side **Contact Form** with fields for `Name`, `Email`, and `Message`.
* Built-in validation checks (required fields and email regex format).
* Success notification alert banner and browser alert upon submission as specified in the challenge guidelines.
* Direct contact links: Email, LinkedIn, and GitHub.
* Downloadable PDF buttons for Resume and extended CV.

### 4. Bonus Features Implemented
* 🐙 **Dynamic GitHub API Repositories:** Asynchronously queries the GitHub REST API (`https://api.github.com/users/steveuniverseuwu/repos`) to dynamically render active public repositories with descriptions, language tags, and star counts (fulfilling Challenge Bonus Requirement #2).
* 🌓 **Theme Mode Switcher:** High-contrast Violet Theme and Pink Theme with instant, non-blocking theme switching and persistent `localStorage` preference memory.
* ⚡ **Zero Framework Overhead:** Ultra-fast load times with pure vanilla code and zero bloated external dependencies.
* 📱 **Full Mobile Responsiveness:** Built-in responsive breakpoints (`860px`, `820px`, `640px`, `560px`) ensuring a clean experience on mobile, tablet, and desktop screens.
* 🌐 **Live Online Deployment:** Hosted with automated CI/CD on Vercel.

## 💻 Local Setup & Viewing Instructions

This website is engineered strictly with native web standards (**Semantic HTML5, Modern CSS3, Vanilla ES6+ JavaScript**) and requires **zero backend installations, zero build steps, and zero external packages**.

### Method 1: Instant Direct Launch (Simplest & Recommended)
No terminal or development server required:
1. Double-click `index.html` directly (or right-click `index.html` → **Open with** → **Google Chrome**, **Microsoft Edge**, or **Firefox**).
2. The portfolio will load instantly with all features active: dynamic theme toggling, interactive QA modal dialogs, client-side form validation, and live GitHub REST API fetching.

### Method 2: Live Server (VS Code / Antigravity IDE)
If reviewing or inspecting the code inside an editor:
1. Open the project folder in VS Code or Antigravity IDE.
2. Right-click `index.html` and click **"Open with Live Server"** (or click **Go Live** on the bottom status bar).
3. The site opens locally at `http://127.0.0.1:5500` or `http://localhost:5520`.

### Method 3: Live Cloud Deployment
You can also inspect the production release online without downloading anything:  
🌐 **Live Deployed Site:** [https://steven-bernabe-portfolio.vercel.app](https://steven-bernabe-portfolio.vercel.app)
